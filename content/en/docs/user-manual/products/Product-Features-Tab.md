## Product Features Tab

The Features tab in RoSaaS allows you to manage and customize the various features available for each product. This tab is essential for defining the capabilities and limits of each product offering.

### Adding a Feature

To add a new feature to a product, follow these steps:

1. **Navigate to the Features Tab:**

   - Log in to your RoSaaS account.
   - Select a product from the Products section.
   - Click on the "Features" tab.

2. **Add Feature:**

   - Click the "Add Feature" button located at the top right corner of the Features tab.

3. **Fill in Feature Details:**

   - **Display Name:** Enter a user-friendly name for the feature.
   - **System Name:** Enter a unique identifier for the feature.
   - **Description:** Provide a brief description of what the feature entails.
   - **Type:** Select the feature type (e.g., Boolean, Number).
   - **Display Order:** Specify the order in which the feature should appear. The order is determined by a numerical value, starting from 1.

4. **Submit Feature:**
   - Click the "Submit" button to save the new feature. The feature will now appear in the list of available features for the product.

### Managing Features

Once features are added, you can manage them through the Features tab:

- **Edit Feature:** Click the three dots (⋮) next to a feature and select "Edit" to modify the feature's details.
- **Delete Feature:** Click the three dots (⋮) next to a feature and select "Delete" to remove the feature from the product.

### Types of Features

- **Boolean:** A feature that can be toggled on or off.
- **Number:** A feature that allows numerical input, useful for specifying limits or quantities.

### Display Order

The Display Order field controls the sequence in which features appear to the tenant. Enter a numerical value to set the order, starting from 1 for the first feature.

By effectively utilizing the Features tab, you can enhance your product offerings by adding and managing specific features tailored to your tenants' needs.
