## Product Custom Specification Tab

The Product Custom Specification Tab in RoSaaS enables you to define and manage custom fields that will be requested in the tenant subscription creation form for specific products. This feature allows for a more tailored subscription process that meets the specific needs of each product.

### Accessing the Product Custom Specification Tab

1. **Log In:** Start by logging in to your RoSaaS account using your credentials.
2. **Main Dashboard:** After successful login, you will land on the main dashboard.
3. **Navigate to “Products”:** In the left-hand navigation menu, locate and click on “Products.”
4. **Select a Product:** From the list of products, select the product for which you want to define custom specifications.
5. **Navigate to “Custom Specification”:** Click on the “Custom Specification” tab for the selected product.

## Creating Product Custom Specifications

To add a new custom specification for a product, follow these steps:

1. **Click on "Add Specification":** In the top right corner of the Custom Specification tab, click on the "Add Specification" button.
2. **Fill in Specification Details:** In the "Add Custom Specification" form, provide the following details:
   - **System Name:** Enter a unique identifier for the specification.
   - **Display Name:** Enter the name that will be displayed for the specification.
   - **Description:** Provide a brief description of the specification.
   - **Is Published:** Toggle this switch to make the specification active.
   - **Is User Editable:** Toggle this switch if the field should be editable by users.
   - **Is Required:** Toggle this switch if the field is mandatory.
   - **Regular Expression:** Define a regular expression for validation.
   - **Validation Failure Description:** Provide a description that will be displayed if the validation fails.
3. **Submit the Specification:** Once you have filled in all the necessary details, click the "Submit" button to create the new custom specification.

### Managing Existing Product Custom Specifications

The Product Custom Specification tab displays a list of all existing custom specifications for the selected product along with their details. You can perform various actions on these specifications:

1. **Edit Specification:** Click on the "..." button in the "Actions" column and select "Edit" to modify the specification details.
2. **Delete Specification:** Click on the "..." button in the "Actions" column and select "Delete" to remove the specification.

### Viewing Product Custom Specifications

The list of custom specifications shows important details including the system name, display name, status, description, whether it is required, whether it is user editable, the regular expression for validation, and the validation failure description. This provides a comprehensive overview of all custom fields that you have defined for the tenant subscription form for the selected product.

By effectively utilizing these functionalities, you can customize the tenant subscription process to include specific fields that are essential for your business operations for each product.
